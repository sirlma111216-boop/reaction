# 그림·소리 자산

이 문서는 `src/shared/content/assets.ts` 에서 만들었다. ID 는 파일 이름이며 바꾸지 않는다.

## 넣는 법

- 그림 원본: `assets-source/images/<ID>.png` (저장소에 넣지 않는다). `npm run assets:build` 가 `public/assets/images/<ID>-<폭>.webp` 와 `index.json` 을 만든다.
- 소리: `public/assets/audio/<ID>.mp3`. `npm run assets:build` 가 `public/assets/audio/index.json` 을 갱신한다.
- 파일이 없는 그림은 점선 상자와 이름으로, 없는 소리는 무음으로 동작한다. `/asset-review` 에서 한눈에 본다.
- `npm run assets:validate` 가 형식(WebP)·투명 배경을 검사해 `reports/asset-coverage.json` 에 쓴다.

## 소리 기본값

- 학생 기기: 배경 음악 꺼짐, 효과음 켜짐(음량 60%).
- 교사 화면: 배경 음악과 짧은 음악 켜짐 (교사로 입장할 때 한 번 적용, 사용자가 바꾼 설정이 있으면 그대로 둔다).
- 설정은 기기에 저장하고 상단 바의 「소리」에서 바꾼다. 첫 터치 전에는 재생하지 않는다.
